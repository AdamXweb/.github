# Contributing

Thanks for your interest in contributing. Pull requests are welcome.

## Pull requests

- For larger changes, open an issue first so the approach can be discussed before you invest time in it.
- Keep each PR focused on one topic.
- Use [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/) for commit messages (`feat:`, `fix:`, `docs:`, `chore:`, …) — this convention is used across these repositories.
- Make sure CI checks pass before requesting review.

## Dependencies

Dependency updates are automated with [Renovate](https://docs.renovatebot.com/) where configured. Please don't open manual dependency-bump PRs unless a specific version is required for a fix.

## Issues

Use the issue templates when filing bugs or feature requests. For security vulnerabilities, follow the [security policy](SECURITY.md) instead of opening a public issue.

## Code of conduct

Participation in these projects is covered by the [Code of Conduct](CODE_OF_CONDUCT.md).
